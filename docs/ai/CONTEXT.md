# Назначение проекта

Проект — boilerplate (стартовый шаблон) для построения RESTful API на Node.js: Express + TypeScript + TypeORM с PostgreSQL. Он даёт готовый каркас бэкенда: JWT-аутентификацию (логин, регистрация, смена пароля), ролевую авторизацию (`ADMINISTRATOR` / `STANDARD`) с проверкой прав и доступа к собственным ресурсам, CRUD-операции над пользователями, middleware для валидации входных данных, определения языка и централизованной обработки ошибок. Слоистая структура (routes → controllers → middleware → ORM-сущности и репозитории) и единый формат успешных и ошибочных ответов задают контракт API, который можно расширять под конкретный продукт.

Проект рассчитан на быстрый старт нового сервиса: Docker Compose поднимает PostgreSQL и API для dev/stage/prod, миграции и сиды наполняют БД демо-данными, а Mocha/Chai/Supertest, ESLint, Prettier, Husky/lint-staged и Conventional Commits обеспечивают тестирование и качество кода. По сути это шаблон, а не готовый бизнес-продукт: предметной логики, кроме аутентификации и управления пользователями, в нём нет — его используют как основу для разработки собственных REST API.
