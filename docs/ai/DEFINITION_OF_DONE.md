# Definition of Done (DoD) — TypeScript

Задача считается выполненной ТОЛЬКО после строгого соблюдения всех пунктов ниже. Не завершай работу, пока не проверишь каждый шаг в терминале и не исправишь все ошибки. Проектные инварианты — [docs/ai/GUARDRAILS.md](GUARDRAILS.md), соглашения по коду — [docs/ai/STYLEGUIDE.md](STYLEGUIDE.md).

## 1. Строгая типизация (Type Safety)

- [ ] `any` запрещён: включены `@typescript-eslint/no-explicit-any` (error) и `noImplicitAny`. Для неизвестных значений используй `unknown` + type guards, для коллекций — дженерики; явные приведения `as` — только при реальной необходимости.
- [ ] Не подавляй ошибки компилятора через `@ts-ignore` / `@ts-expect-error` и не используй приведение `as SomeType` без реальной необходимости.
- [ ] Утилиты имеют явный тип возврата (например, `createJwtToken(): string`); публичные контракты используют типы из `src/types/`.
- [ ] Новые env-переменные описаны в `src/types/ProcessEnv.d.ts`.

## 2. Чистота и качество кода

- [ ] Удалены отладочные выводы (`console.log`, `console.debug`, `debugger`) и закомментированные блоки кода.
- [ ] Нет неиспользуемых импортов, переменных и параметров.
- [ ] Секреты, токены и URL-адреса окружений вынесены в переменные окружения (`process.env`); новые ключи добавлены в `.env` и `config/*.env` (для stage/prod) и в `src/types/ProcessEnv.d.ts`.

## 3. Тестирование

- [ ] Для новой бизнес-логики и утилит написаны тесты на Mocha + Chai + Supertest (`*.test.ts` рядом с кодом).
- [ ] Учтены граничные случаи (edge cases): пустые массивы, `null`, `undefined`, ошибки сети/базы данных.
- [ ] Все существующие и новые тесты проходят успешно (нужен запущенный PostgreSQL).

## 4. Обязательные проверки в терминале (Quality Gates)

Перед финальным ответом последовательно запусти в терминале и убедись, что каждая команда завершилась со статусом `0`:

- [ ] **Проверка типов во всем проекте:** `npm run tsc` (гарантирует, что правки не сломали соседние модули).
- [ ] **Линтер и форматирование:** `npm run lint` (ошибок и предупреждений быть не должно).
- [ ] **Запуск тестов:** `npm test` (все тесты зеленые).
- [ ] **Тестовая сборка:** `npm run build` (сборка в `dist/` проходит без ошибок).

## 5. Документация и отчет

- [ ] Если менялись API-эндпоинты, схемы БД или CLI-команды, обновлена соответствующая документация / README.
- [ ] Инварианты из `docs/ai/GUARDRAILS.md` не нарушены (или отступление согласовано и описано).
- [ ] В финальном ответе пользователю приложен краткий список измененных файлов с пояснением, что и зачем было сделано.
